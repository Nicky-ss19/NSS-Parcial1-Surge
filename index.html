¿De qué trata?

De integración continua. O sea, esta página no la subí a mano: cada vez que hago git push a la rama main, GitHub Actions la publica solita en Surge.sh 🚀

¿Cómo funciona?

  1. Escribo la página en mi compu, en mi repositorio local.
  2. Hago git push a GitHub.
  3. GitHub Actions lee el archivo .github/workflows/main.yml y arranca solo.
  4. Instala Surge y publica la página con mi token.

¿Y la clave de Surge?

Pues no está en el código. La guardé como secret en GitHub, así nadie la ve, pero GitHub Actions sí la puede usar 🔒
